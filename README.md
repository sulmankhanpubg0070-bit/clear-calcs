# Simple Calc

Build a simple Calculator App with a clean modern mobile-first interface. Include a calculator display screen and buttons for digits 0-9, decimal point, addition, subtraction, multiplication, division, equals, clear, and delete/backspace. Show calculation history section below the calculator. Make the UI responsive and easy to use on Android devices. Use large buttons, clear typography, and smooth interactions. Include error handling for division by zero and invalid inputs. Prepare the project so it can later be exported and packaged as an Android APK.
